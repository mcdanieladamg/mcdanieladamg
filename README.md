@mcdanieladamg

I build tools and experiment with AI in my spare time, exploring how to ensure AI agent reliability in solving complex, real-world problems.

Further than just making AI output reliable, it needs to be verifiable. My tools explore preserving context across long projects, making reasoning and evidence inspectable, and connecting generated work to checks that can establish whether it is correct.

## Featured project: ValidatedWorld

I created [ValidatedWorld](https://github.com/mcdanieladamg/ValidatedWorld), an open-source AI agent skill, also available as an OpenAI plugin, for keeping project knowledge coherent beyond an agent's context window.

It connects project facts, decisions, evidence, and dependencies so agents can retrieve relevant context and review the consequences of proposed changes. The goal is to help maintain consistency as a project evolves.
